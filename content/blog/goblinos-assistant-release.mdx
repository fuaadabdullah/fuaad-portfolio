## What It Is

GoblinOS Assistant is a multi-provider, privacy-first AI assistant with intelligent model routing. The UI pairs a chat experience with live system status panels so you can see provider health and routing behavior at a glance.

## What’s Included

- Chat interface with system status panels
- Multi-provider routing with intelligent selection
- FastAPI backend (Python)
- Next.js frontend (React/TypeScript)
- Cloudflare edge + Vercel frontend
- Docker + Terraform infrastructure
