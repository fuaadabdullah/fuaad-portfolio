## Do's and Don'ts

### ✅ Do
- Use high-quality project images
- Lead with measurable project outcomes
- Include inline screenshots or demo previews
- Keep descriptions concise
- Provide clear call-to-action links

### ❌ Don't
- Use low-resolution images
- Lead only with tech stack details
- Hide proof media behind external links
- Hide important project links

## Accessibility

- Images have descriptive alt text
- Links are properly labeled
- Outcomes and technology lists are accessible
- Keyboard navigation works for all actions
